Community site sections

Sections from a volunteer group's site, modelled on lzr.life: a catalog to browse, a how-to, and events. These lean on the content and form components more than the studio sections do. The rules behind them are on Composition.

Welcome with a quote

The whole site is re-themed from one input on the root element. Here it is on the section instead, so you can see it next to the default theme.

Same markup in both builds 
<section class="retheme prose" style="--primary: #a33b2b; --neutral: #6b6150; max-width: 40rem">
  <h1>Little Zine Revolution</h1>
  <p>We curate and distribute anti-colonial zines. Little actions have ripple effects.</p>
  <blockquote>
    You have to act as if it were possible to radically transform the world. And
    you have to do it all the time.
    <footer class="text-secondary"><small>Angela Davis</small></footer>
  </blockquote>
  <a href="#" class="btn">Explore the zine catalog</a>
</section>
  • Boundary: --primary sets the button and the quote's rule. --neutral sets what text and surfaces are tinted with, so the page reads warm and muted while the brand colour stays saturated.
  • Text: the attribution sits inside the blockquote so the quote's rule runs the full height of both.

Event list

Each event is a row: the date, what and where, and an add-to-calendar menu. The menu is a native <details>, so it needs no script.

Same markup in both builds 
<ul style="list-style: none; padding: 0; display: grid; gap: var(--padding)">
  <li class="card-border flex flip" style="align-items: center">
    <div style="text-align: center; min-width: 4rem">
      <small class="text-secondary">NOV</small>
      <div><strong style="font-size: 1.5rem">14</strong></div>
    </div>
    <div style="flex: 1">
      <strong>Folding party</strong>
      <p class="text-secondary"><small>Saturday, 2 to 4 pm · Belmont Library</small></p>
    </div>
    <details style="position: relative">
      <summary class="btn btn-secondary">Add to calendar</summary>
      <ul class="dropdown-content menu" style="position: absolute; right: 0; margin-top: calc(var(--padding) / 4); list-style: none">
        <li><a href="#" class="semantic menu-item">Google Calendar</a></li>
        <li><a href="#" class="semantic menu-item">Apple / Outlook (.ics)</a></li>
      </ul>
    </details>
  </li>
  <li class="card-border flex flip disabled" style="align-items: center">
    <div style="text-align: center; min-width: 4rem">
      <small class="text-secondary">OCT</small>
      <div><strong style="font-size: 1.5rem">03</strong></div>
    </div>
    <div style="flex: 1">
      <strong>Zine swap</strong>
      <p class="text-secondary"><small>Past event · Community center</small></p>
    </div>
  </li>
</ul>
  • Layout: the list is a grid for its gap, and each row is .flex .flip, so on a phone the date, details and button stack.
  • Surfaces: .dropdown-content only paints. Where it opens is the caller's job: a relative <details> and an absolute panel.
  • Boundary: a past event takes .disabled, which sets --chroma: 0 on the row. Everything in it loses its colour together, with no per-element overrides.

Guide sections

Long how-to content folds into collapses, one per question. Each body is prose.

Same markup in both builds 
<details class="collapse" open>
  <summary class="collapse-title">How do I fold a quarter-page zine? <span>−</span></summary>
  <div class="collapse-content prose">
    <ol>
      <li>Fold the sheet in half along the long edge.</li>
      <li>Fold it in half again.</li>
      <li>Crease well and trim the top fold.</li>
    </ol>
  </div>
</details>
<details class="collapse">
  <summary class="collapse-title">Can I print double sided at home? <span>+</span></summary>
  <div class="collapse-content prose">
    <p>Yes. Flip on the short edge so the back pages are not upside down.</p>
  </div>
</details>
  • Text: .prose goes on .collapse-content, not on the stack, so the titles keep their own size and spacing.

Credit band

A small block that belongs to someone else, in their colour, at the foot of the page.

Same markup in both builds 
<aside class="card-border retheme flex flip" style="--primary: rebeccapurple; align-items: center; justify-content: space-between">
  <div class="prose">
    <h3>Want a site like this?</h3>
    <p class="text-secondary">Built by a one-person studio in Portland.</p>
  </div>
  <a href="#" class="btn">Book a free call</a>
</aside>
  • Boundary: .retheme with the studio's own --primary marks the block as separate from the group's theme without a single extra rule.
  • Spacing: the prose column keeps its bottom margins; align-items: center on the row centres the button against the whole block.
