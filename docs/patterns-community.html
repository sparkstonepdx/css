Community site sections

Sections from lzr.life, a volunteer group's zine library, rebuilt in the class build. The sections, headings, labels and links are the site's. Longer body text is shortened, and the layout inside each section is a plain arrangement of framework pieces rather than a copy of the site's styling. Images are placeholders. The rules behind them are on Composition.

Navigation

A home link and the five sections of the site.

Same markup in both builds 
<nav class="navbar">
  <div class="navbar-start">
    <a href="#" class="semantic" aria-label="Home"><strong>LZR</strong></a>
  </div>
  <div class="navbar-end" style="flex-wrap: wrap">
    <a href="#" class="link">Zines</a>
    <a href="#" class="link">How To</a>
    <a href="#" class="link">Events</a>
    <a href="#" class="link">LZR in the Wild</a>
    <a href="#" class="link">Get in Touch</a>
  </div>
</nav>
  • Layout: .navbar-end is a flex row, so with five links it needs flex-wrap: wrap to survive a phone.

  </blockquote>

</section>
  • Text: one .prose spaces the short lines, the quote and the button. Each line is its own paragraph, so each gets the same 1rem beat.

Zine page

One zine: its cover, what kind of zine it is, its tag, and the PDF to preview or download. Beside it on the site sits the studio's credit card, shown further down this page.

Same markup in both builds 
<article class="flex flip">
  <div style="flex: 0 0 12rem; aspect-ratio: 3 / 4; background: var(--surface-strong); border-radius: var(--border-radius)" role="img" aria-label="Butterfly cover"></div>
  <div class="prose" style="flex: 1">
    <h2>Butterfly</h2>
    <p class="text-secondary">Single-sided, 8-page mini zine · Inspiration</p>
    <p><span class="badge">Single Sided</span></p>
    <div class="flex" style="flex-wrap: wrap">
      <a href="#" role="button" class="btn">Download PDF</a>
      <a href="#" role="button" class="btn btn-secondary">Preview</a>
    </div>
  </div>
</article>
  • Text: the format and category are .text-secondary; the tag is a .badge, the same tag the catalog filters on.
  • Actions: download is the filled button because it is why the visitor came; preview is secondary.
