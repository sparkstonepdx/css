Divider

A rule between blocks of content. Kobalte's Separator renders role="separator" with its orientation on it, so it needs no class.

alpha The class names and states here are stable. The look is not: these styles can change in a minor release, without a major version bump.

ClassDoes what
dividerA horizontal rule with vertical margins
divider-verticalA vertical rule, for a flex row

Basic

<div>Above the rule.</div>
<hr class="divider" />
<div>Below it.</div>
<div class="flex" style="align-items: center">
  <span>Left</span>
  <hr class="divider divider-vertical" style="height: 1.5rem" />
  <span>Right</span>
</div>
<div>Above the rule.</div>
<hr class="divider" />
<div>Below it.</div>
<div class="flex" style="align-items: center">
  <span>Left</span>
  <hr class="divider divider-vertical" style="height: 1.5rem" />
  <span>Right</span>
</div>
import { Separator } from "@kobalte/core/separator";

<Separator />
<Separator orientation="vertical" />
<div>Above the rule.</div>
<hr role="separator" data-orientation="horizontal" />
<div>Below it.</div>
<div class="flex" style="align-items: center">
  <span>Left</span>
  <hr role="separator" data-orientation="vertical" style="height: 1.5rem" />
  <span>Right</span>
</div>

A bare <hr> is prose: it takes the typography rule inside .prose and the tight rule inside a .menu. .divider is the standalone one.

Composition

Common ways to put this together with other components. The general rules are on Composition.

Between groups in a toolbar

A vertical divider splits a row of actions into groups.

Same markup in both builds 
<div class="flex" style="align-items: center; gap: calc(var(--padding) / 4)">
  <button class="btn btn-ghost">Undo</button>
  <button class="btn btn-ghost">Redo</button>
  <div class="divider divider-vertical" style="height: 1.5rem; margin: 0 calc(var(--padding) / 2)"></div>
  <button class="btn btn-ghost">Share</button>
  <button class="btn btn-secondary">Export</button>
</div>
  • Layout: a vertical divider takes its height from you; give it about a line of text.

Between a page and its footer

A horizontal divider starts the footer without boxing it.

Same markup in both builds 
<p>The last paragraph of the page.</p>
<footer>
  <hr class="divider" />
  <p class="text-secondary"><small>A short line of small print.</small></p>
</footer>
  • Surface: .divider is the same colour as a .card-border border, so it belongs to the same family.
