Prose

Long-form content: paragraphs, headings, lists, quotes, rules and code. The classless build styles these elements everywhere. The class build scopes them to .prose, so a paragraph inside a component keeps its own spacing.

ClassDoes what
proseStyles p, h1 to h6, ul, ol, li, blockquote, hr, code, pre, samp and kbd inside it
kbdKey cap, usable outside .prose

Headings and paragraphs

<div class="prose">
  <h1>Heading one</h1>
  <h2>Heading two</h2>
  <h3>Heading three</h3>
  <p>Body text sits at 18px with a 1rem bottom margin.</p>
</div>
