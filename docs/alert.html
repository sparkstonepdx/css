Alert

A short, important message. Kobalte's Alert is one element with role="alert", which the Kobalte layer binds, so it needs no class at all.

ClassDoes what
alertThe message box
alert-errorRecolours it with --error-color

Basic

<div class="alert" role="alert">Your changes have been saved.</div>
<div class="alert alert-error" role="alert">We could not reach the server.</div>
<div class="alert" role="alert">Your changes have been saved.</div>
<div class="alert alert-error" role="alert">We could not reach the server.</div>
import { Alert } from "@kobalte/core/alert";

<Alert>Your changes have been saved.</Alert>
<Alert class="alert-error">We could not reach the server.</Alert>
<div role="alert">Your changes have been saved.</div>
<div role="alert" class="alert-error">We could not reach the server.</div>

daisyUI also has alert-info, alert-success and alert-warning. This framework derives everything from one --color plus --error-color, so there are no tokens for those yet.
