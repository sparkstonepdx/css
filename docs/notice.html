Notice

The phone's toast. Notices open low, just above the dock, where the thumb and the eyes already are, and stack upward. How long each stays and showing one at a time come from @sparkstone/kit.

alpha The class names and states here are stable. The look is not: these styles can change in a minor release, without a major version bump.

ClassDoes what
noticesThe stack, fixed above the dock (reads --dock-h)
noticeOne message: an edged card on a tint
notice-successSomething worked
notice-warningSomething to be careful about
notice-errorSomething went wrong
notice-artThe thing it's about, in a coin
notice-textA bold line and an optional detail in <small>
notice-actionsUndo, Edit

Basic

The stack is shown in place here rather than fixed to the bottom.

Same markup in both builds 
<ul class="notices" style="position: static; padding: 0">
  <li class="notice">
    <span class="notice-art" aria-hidden="true">🍼</span>
    <span class="notice-text"><strong>Logged bottle 90 ml</strong><small>Use by 12:11 PM</small></span>
    <span class="notice-actions"><button class="btn btn-sm">Undo</button></span>
  </li>
  <li class="notice notice-success">
    <span class="notice-text"><strong>Invite link copied</strong></span>
  </li>
  <li class="notice notice-warning">
    <span class="notice-text"><strong>Syncing…</strong><small>Your changes are saved on this phone.</small></span>
  </li>
  <li class="notice notice-error">
    <span class="notice-text"><strong>The server isn't answering.</strong><small>Your moves go through once it's back.</small></span>
  </li>
</ul>
