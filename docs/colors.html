Colors

A few inputs, set anywhere, and a small set of colours derived from them on every element. Pick any colour, put it on any element, and everything inside re-themes around it.

alpha The class names and states here are stable. The look is not: these styles can change in a minor release, without a major version bump.

Inputs

ClassDoes what
--primaryThe brand colour. Its own hue and chroma are kept; only the lightness is pinned per role
--secondaryLinks. Defaults to the primary rotated 180 degrees
--neutralWhat text and surfaces are tinted with. Defaults to the primary
--errorInvalid fields, error text, error alerts

Live preview

Change these and every page on this site updates. Values persist for the session.

Derived colours

Components read these, never the inputs. Text colours are solid, so their contrast never depends on what sits behind them. Surfaces and rules are a tinted mid-tone at partial opacity, so they carry the theme's colour, stack when nested, and flip with the scheme on their own.

--bg Page
--surface Raised, 30%
--surface-strong Raised, 63%
--divider Rules, 30%
--fg Text
--fg-muted Secondary text
--fg-faint Disabled text
--line Borders, focus, fills
--primary-text Brand text
--primary-fill Filled button
--on-primary-fill Text on it
--link Links

Apply anywhere

Every derived colour is recomputed on each element from the inputs it inherits, so setting one on any element is enough. These are nested sections, each setting a single input:

Same markup in both builds 
<section class="card-border" style="--primary: tomato">
  <p><code>--primary: tomato</code></p>
  <button class="btn">Save</button>
  <input class="input" placeholder="A field" style="margin: 0.75rem 0" />
  <section class="card-border" style="--primary: #0a7d6b">
    <p><code>--primary: #0a7d6b</code>, one level down</p>
    <button class="btn btn-secondary">Cancel</button>
    <a href="#" class="link">A link</a>
    <section class="card-border disabled" style="margin-top: 0.75rem">
      <p><code>.disabled</code>: one declaration, <code>--chroma: 0</code></p>
      <button class="btn">Save</button>
    </section>
  </section>
</section>

Brand colours keep their character

Only the lightness is pinned per role. A muted brand stays muted and a grey one stays grey, where 2.x kept only the hue and replaced the chroma. Chroma is still capped per role, so a vivid colour at a very light or very dark lightness stays in gamut.
