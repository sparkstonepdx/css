Link

Links use the accent color, which is the theme color rotated 180 degrees in oklch unless you set --accent-color yourself.

ClassDoes what
linkAccent-colored text with a pointer cursor

Basic

<p>Read the <a href="#" class="link">installation guide</a> to get started.</p>
<p>Read the <a href="#">installation guide</a> to get started.</p>

Recoloring

Set --accent-color on any ancestor to change links in that subtree.

<p style="--accent-color: teal">A <a href="#" class="link">teal link</a> inside a scoped block.</p>
<p style="--accent-color: teal">A <a href="#">teal link</a> inside a scoped block.</p>

Unstyled links

<a href="#">No accent color, no underline</a>
<a href="#" class="semantic">No accent color, no underline</a>

Classless: <code>.semantic</code> also removes the focus ring, since it unsets every property. Prefer the class build when you need unstyled links to stay keyboard accessible.
