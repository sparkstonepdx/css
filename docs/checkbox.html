Checkbox

A custom check drawn with a rotated border, filled from the theme color when checked. Wrap it in a label to get the row layout.

ClassDoes what
checkbox1.5rem box with a drawn check mark
labelOn the wrapping label: row layout with a gap

Basic

<label class="label">
  <input type="checkbox" class="checkbox" checked />
  Email me about releases
</label>
<label class="label">
  <input type="checkbox" class="checkbox" />
  Email me about everything else
</label>
<label>
  <input type="checkbox" checked />
  Email me about releases
</label>
<label>
  <input type="checkbox" />
  Email me about everything else
</label>
