3.0: a new colour engine. Set `--primary` (or 2.x's `--color`), `--secondary`, `--neutral` and `--error` on any `.retheme` element and its subtree re-themes; the nine-step `--*-lc-*` scale is gone in favour of named colours (`--fg`, `--fg-muted`, `--surface`, `--line`, `--primary-fill` and so on). Disabled and invalid states are two generic rules. Adds entrance and state-change animations on `--duration-change` and `--duration-enter`, and the docs gain composition examples.
